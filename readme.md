# AI-Powered Chatbot Project

## Project Overview
This project is a personal implementation of an AI-powered chatbot designed to demonstrate my skills in building intelligent conversational agents. The chatbot leverages modern AI techniques and is built with scalability and modularity in mind.

## Features
- Interactive chatbot capable of understanding and responding to user queries.
- Modular architecture for easy integration with various services.
- Dockerized setup for seamless deployment.

## Technologies Used
- **Python**: Core programming language for the chatbot logic.
- **Docker**: Containerization for easy deployment.
- **MCP (Model Context Protocol)**: For managing communication between the chatbot and external services.

## Learning Outcomes
- Gained hands-on experience with MCP architecture.
- Improved understanding of building scalable AI systems.
- Enhanced skills in containerization and deployment using Docker.

## How to Run the Project
1. Clone the repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Run the server using `python main.py`.
4. Optionally, build and run the Docker container using the provided `Dockerfile`.
